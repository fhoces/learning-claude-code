Learning Claude Code

An 8-module course on working with Claude Code as a daily tool for applied research and data work. The practices (version control, documentation, verification, token budgeting) and the extension mechanisms (memory, skills, hooks, mods) that make an agentic coding session safe, cheap, and reproducible. Every module is concept → show → drill.

Quick start

git clone https://github.com/fhoces/learning-claude-code
cd learning-claude-code
Rscript data/build_data.R      # build the practice dataset
cat module-01/exercise.md      # then open a Claude Code session
